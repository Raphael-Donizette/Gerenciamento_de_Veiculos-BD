#  Sistema de Gerenciamento de Veículos em C

Sistema modular desenvolvido em **Linguagem C** como parte das práticas da disciplina de Algoritmos e Estruturas de Dados (AEDS). O software gerencia um banco de dados de veículos utilizando vetores de registros (`struct`) alocados na memória RAM e persistência de dados em arquivos de texto[cite: 10].

---

##  Funcionalidades do Sistema
* **Persistência de Dados:** Sincronização automática entre a memória RAM e o arquivo de banco de dados físico[cite: 10].
* **Buscas Otimizadas:** Consultas sequenciais por placa, tipo de câmbio, combustível e potência do motor[cite: 10].
* **Filtros por Faixa de Preço:** Listagem de veículos com base em limites orçamentários[cite: 10].
* **Geração de Relatórios Estatísticos:** 
  * Porcentagem de veículos por categoria (SUV, Sedã, Hatch, etc.) e tipo de combustível[cite: 10].
  * Identificação do veículo 1.6 mais barato (com simulação de financiamento em 60 meses)[cite: 10].
  * Identificação do veículo Flex Automático mais caro (com estimativa de seguro anual)[cite: 10].
  * Estatísticas de veículos com até 5 anos (média de quilometragem)[cite: 10].
* **Gerenciamento Completo:** Adição e remoção dinâmica de registros com atualização imediata do arquivo[cite: 10].

---

##  Tecnologias Utilizadas
* **Linguagem:** C
* **Conceitos:** Vetores de Registros (`struct`), Ponteiros, Alocação, Modularização, Manipulação de Arquivos e Funções Matemáticas (`math.h`)[cite: 10].
